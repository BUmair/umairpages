# Umair Bhalli · Portfolio

Static portfolio site for IT support, AWS cloud and serverless automation work. Plain HTML and CSS, no build step.

**Live site:** https://bumair.github.io/umairpages/

## Pages

- `index.html`: home page
- `clearhome-contributions.html`: Clear Home case study
- `aws-*.html`: AWS documentation pages (static site, infrastructure, REST API, serverless automation)

## Preview locally

Open `index.html` in a browser, or run `python3 -m http.server 8000` in this folder and visit http://localhost:8000.

What I built

A routing workflow for uploads. A file dropped into an input bucket is sent to one of three Lambda functions, based on its folder and file type. The function writes its output to a separate bucket, and CloudWatch logs each run.

Decisions

  • Event notifications instead of polling. S3 calls the function when a file arrives, so no compute runs while the bucket is idle.
  • Separate input and output buckets. Results never land in the bucket that triggers the functions, so they can't start another run.
  • One notification per type. Each rule matches one folder and file type, so every upload triggers exactly one function.
  • Least privilege. Each function's role can read only its own input files and write only to the output folder.

The current handler copies each file to the output bucket. It's the starting point, and the next step is to add the real processing for each file type. The same code runs in all three functions:

import json
import urllib.parse
import boto3

s3 = boto3.client("s3")
OUTPUT_BUCKET = "documents-processed-example"

def lambda_handler(event, context):
    processed = []
    for record in event["Records"]:
        bucket = record["s3"]["bucket"]["name"]
        key = urllib.parse.unquote_plus(record["s3"]["object"]["key"])
        body = s3.get_object(Bucket=bucket, Key=key)["Body"].read()
        output_key = "processed/" + key.split("/")[-1]
        s3.put_object(Bucket=OUTPUT_BUCKET, Key=output_key, Body=body)
        print(json.dumps({"input": key, "output": output_key, "bytes": len(body)}))
        processed.append(output_key)
    return {"processed": processed}

What broke and how I fixed it

  • A function didn't run for an uppercase file extension. The suffix match is case-sensitive, so .CSV doesn't match .csv. Fix: upload lowercase extensions, or add a rule for each capitalization.
  • A function ran over and over. Its output was written to the folder that triggers it. Fix: write results only to the output bucket.
  • S3 refused to save a new event rule. Two rules had the same prefix and suffix. Fix: give each rule a unique folder and file type.
  • The logs showed AccessDenied. The role's policy named a different folder or bucket than the code used. Fix: I compared the names in the policy with the names in the code.
  • Large files stopped partway through. The timeout was too short. Fix: I raised the timeout.

Clear Home: what I did

Clear Home was built by a team of four for GDG Build with AI x Hacktoberfest 2026. This page lists my contributions, each linked to its commit in the team repository.

Listing tools Frontend and accessibility Chat safety and fallback Listing photos Review and handoffs

Listing tools

  • Save button on every listing and a Favorites tab, stored in the browser with no account.
  • Share button that copies a link to the listing, and opening the link pins that listing first.
  • Quick picks and four main filters in one row, with the rest under More filters; results update as filters change.
  • Active-filter summary with a Reset button, and a next-step button on each card that matches its status: call, apply, join a waitlist, or confirm.
  • Save and Share as icon buttons at the top of each card, with compact link pills.
  • Button labels match the listing: "Contact to Apply" when a phone is listed, "Apply on Provider Site" when only a website is.
  • Shorter photo strip and one-line links on listing cards, and whole-dollar prices.

Frontend and accessibility

  • Modernized the frontend with guided forms and a responsive layout.
  • Labelled the sidebar as a section to fix an accessibility landmark issue on the tools page, and raised text under 12px to 12px.
  • Darkened the blue behind the hero text so white text passes contrast, from 1.6–2.3:1 to 5.3–6.5:1.
  • Fitted the home map into a compact responsive frame.

Chat safety and fallback

  • Expanded the detection patterns so threat and weapon messages get the 911 and hotline answer first, not a housing list.
  • The resources chat falls back to verified resources when the AI is unavailable, and says so when a question has no topic instead of listing unrelated homes.

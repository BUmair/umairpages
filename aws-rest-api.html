What I built

An items API. Anyone can list or read items. Only signed-in users can create or delete them. API Gateway routes requests, Lambda runs the logic, DynamoDB stores the items, and Cognito issues the tokens.

Back to top ↑

Decisions

  • Public reads, protected writes. The JWT authorizer is attached to POST and DELETE only. Without a token, those routes return 401.
  • One shared integration. All four routes invoke the same Lambda function.
  • Least privilege. The Lambda role can use only Scan, GetItem, PutItem, and DeleteItem, and only on the one table.
  • Logging. Each request writes a line to CloudWatch Logs.

Architecture

The client signs in with Cognito to get a token. API Gateway checks the token on the write routes, then invokes the Lambda function.

Routes

  • GET — /items — Public — List all items
  • GET — /items/{id} — Public — Get one item
  • POST — /items — JWT — Create an item
  • DELETE — /items/{id} — JWT — Delete an item

Back to top ↑

How I verified it

  • GET /items returned 200 and an empty list.
  • POST and DELETE without a token returned 401.
  • POST with a Cognito ID token returned 201, and the item appeared in the next GET.
  • DELETE with a token returned 204, and the next GET returned an empty list.

I ran the authenticated checks with curl, using a token from Cognito's sign-in call.

What broke and how I fixed it

  • Runtime.HandlerNotFound on every request. The console's default handler name didn't match the code. Fix: I set the handler to lambda_function.handler.
  • GET /items returned 404 after cleanup. Removing the extra integrations also removed the route's integration. Fix: I recreated the route and attached the shared integration.
  • An integration couldn't be deleted. A route still referenced it. Fix: I pointed each route at the shared integration first, then deleted the extra ones.
  • Sign-in failed with a temporary password. Users created in the console must change their password at first sign-in. Fix: I answered the NEW_PASSWORD_REQUIRED challenge with RespondToAuthChallenge.
